# Feature Boundaries

## Implemented Features

- Docker Compose local environment.
- Next.js operations console.
- FastAPI shipment, compliance, document, intelligence, and gateway services.
- PostgreSQL persistence.
- Neo4j shipment graph projection.
- Redis-backed compliance job state when enabled.
- MinIO document storage.
- Shipment, consignment, route leg, and event APIs.
- Deterministic compliance rule evaluation.
- Versioned demo regulation rules.
- Evidence records linking assessments, rules, documents, and events.
- Basic PDF/text extraction for uploaded documents.
- Consistency checks and one-question-at-a-time information gain.
- Mock-first HS-code recommendation prototype.
- Synthetic scikit-learn risk scoring prototype.
- Deterministic route comparison and regulation impact analysis.
- HTML/PDF compliance report generation.
- Demo authentication, RBAC, audit logs, and normalized API errors.
- Health checks, unit tests, Docker docs, API docs, architecture diagram,
  threat model, and legal disclaimer.

## Mock Or Demo Features

- Demo authentication tokens.
- Demo compliance rules for India, UAE, and Germany.
- Seeded tariff taxonomy.
- Synthetic customs outcome dataset.
- Weighted route scoring, estimated duty, and FTA eligibility.
- Regulation source URLs.
- Corrective actions.

## Future Startup Features

- Production OIDC/SAML authentication.
- Tenant isolation and user management.
- Real legal content ingestion and citation management.
- Customs broker workflow integrations.
- Official tariff and duty calculation integrations.
- Production OCR and document understanding.
- Human-in-the-loop classification review.
- Route optimization with carrier schedules and live disruption data.
- Immutable audit/event ledger.
- Security monitoring, rate limits, and production secrets management.
- Real customs filing, where legally and commercially appropriate.
